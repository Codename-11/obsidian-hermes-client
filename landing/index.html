Hermes Agent × Obsidian

Chat with Hermes from your vault.

Hermes Client is a desktop Obsidian plugin for any reachable Hermes Agent API Server. It supports session chat, streaming responses, current-note context, and image paste/drop without storing provider keys or taking over your vault.

GitHub repo Hermes docs

Generic by design

Configure any Hermes API base URL and optional bearer token. No hardcoded profile, operator, host, or vault.

Streaming default

Uses POST /api/sessions/{id}/chat/stream with a non-stream fallback setting for troubleshooting.

Image-aware

Paste screenshots, drag/drop images, or attach files. Images are sent through Hermes API attachments.

Safe boundary

No autonomous vault mutation in v1. Current-note context and image uploads happen only from explicit user actions.
